# Smart Soil Moisture Analysis Using KiwisIoT Platform

## 📌 About the Project

Smart Soil Moisture Analysis Using KiwisIoT Platform is an IoT-based smart agriculture project designed to monitor soil moisture levels in real time.

Using a microcontroller and a soil moisture sensor, the system measures the amount of moisture present in the soil and identifies whether the soil is dry, moderately moist, or sufficiently wet.

The collected sensor data is transmitted through Wi-Fi to the KiwisIoT platform, where users can visualize and monitor real-time soil moisture readings through an online dashboard from anywhere.

This project helps farmers and gardeners understand soil conditions, make better irrigation decisions, avoid unnecessary water usage, and support efficient smart agriculture practices.
